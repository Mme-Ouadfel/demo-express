# demo-express

Petit projet de démonstration du backend pour le chapitre 2. Il ne sert pas de base au projet final.

## Prérequis
- Node.js LTS 20.11 ou supérieur
- npm
- Git

## Installation

```bash
git clone URL_DU_DEPOT
cd demo-express
copy .env.example .env
# macOS/Linux : cp .env.example .env
npm install
```

## Lancement

```bash
npm run dev
```

Ouvrir http://localhost:3000.
